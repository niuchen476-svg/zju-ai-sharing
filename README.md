# 今天，我们怎么更好地用 AI 做事？

面向浙江大学实践队的 HTML 主题分享。

## 使用

- 在线打开 GitHub Pages 地址
- `← / →`、空格、PageUp / PageDown 翻页
- `Home / End` 跳至首尾
- `F` 全屏
- 左上角悬停后可进入编辑模式并导出修改后的 HTML

## 内容

全篇 21 页，目录采用纵向单列结构，六个板块各有独立章节过渡页：AI 术语、国内外模型分析、实际操作过程、小工具分享、个人看法，以及如何获取国外 AI。第一章用一张三列表格集中解释常见术语；第二章用三页分别呈现七款 AI 的定位与付费、国内外用户规模及选择结论；第三章用真实的防台风安全网页案例和原始对话截图，拆解需求、材料、迭代、失败重试与 GitHub Pages 交付；第四章用一张表集中介绍 Everything、WizTree、PowerToys、QuickLook、LocalSend、uBlock Origin、沉浸式翻译、猫抓和 OneTab，并提供可点击的官方下载或官方扩展商店入口；第五章讨论 AI 提速之后仍需由人完成的理解、协作、沟通和责任，并保留分享者最初写下的原始手记；第六章只梳理网络环境、个人账号和支付渠道的准备顺序，不展开具体操作教程。

## 图片
