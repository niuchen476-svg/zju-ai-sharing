# AI：每个人的第二种能力

面向浙江大学跨专业实践队的 20–30 分钟 HTML 主题分享。

## 使用

- 在线打开 GitHub Pages 地址
- `← / →`、空格、PageUp / PageDown 翻页
- `Home / End` 跳至首尾
- `F` 全屏
- 左上角悬停后可进入编辑模式并导出修改后的 HTML
