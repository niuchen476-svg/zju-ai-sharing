# 今天，我们怎么用 AI 做事？

面向浙江大学跨专业实践队的 20–30 分钟 HTML 主题分享。

## 使用

- 在线打开 GitHub Pages 地址
- `← / →`、空格、PageUp / PageDown 翻页
- `Home / End` 跳至首尾
- `F` 全屏
- 左上角悬停后可进入编辑模式并导出修改后的 HTML

## 内容

全篇 19 页，目录采用纵向单列结构，五个板块各有独立章节过渡页：AI 术语、国内外模型分析、实际操作过程、小插件分享，以及个人看法。第一章用一张三列表格集中解释常见术语；后续内容从不同专业的真实任务出发，覆盖任务简报、研究核验、轻量工具搭建与交付，并讨论 AI 提速之后仍需由人完成的理解、创造、沟通和责任。
