# 今天，我们怎么用 AI 做事？

面向浙江大学跨专业实践队的 20–30 分钟 HTML 主题分享。

## 使用

- 在线打开 GitHub Pages 地址
- `← / →`、空格、PageUp / PageDown 翻页
- `Home / End` 跳至首尾
- `F` 全屏
- 左上角悬停后可进入编辑模式并导出修改后的 HTML

## 内容

从不同专业的真实任务出发，介绍工具选择、使用方法、农学与文本研究案例、轻量工具搭建，以及 AI 提速之后仍需由人完成的理解、判断、沟通和责任。
